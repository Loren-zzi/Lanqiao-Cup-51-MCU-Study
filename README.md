# 蓝桥杯单片机学习资料

这是我备考蓝桥杯单片机赛道时整理的练习工程、源码和参考文档，主要使用 STC15F2K60S2 与 Keil C51。

## 从哪里开始

- `蓝桥杯20天复习/`：按知识点和赛题整理的练习工程。前面从数码管、按键、串口和常见外设入手，后面是模板与省赛题练习；源码里补充了面向初学者的中文注释。
- `寒假/`、`KerilProject/`：其他阶段的练习工程。
- `程序源码（江协C51代码）/`、`蓝桥杯单片机(lyf代码资料)/`：参考源码和相关文档。
- 根目录中的 PDF：竞赛板原理图和使用说明。

建议先阅读每个工程的 `main.c`，再顺着 `ds1302.c`、`onewire.c`、`iic.c` 等驱动文件了解外设通信。部分文件沿用原工程的 GBK 编码，部分官方驱动示例为 UTF-8；用 Keil 打开时请留意编码。

这些是学习过程中的原始练习，有些后期工程保留了调试代码或未完成的片段。代码中的注释会标出已发现的明显问题，使用前请按自己的开发板和晶振配置检查、编译并实测。

仓库只收录源码、工程配置和文档。软件安装包、压缩包与编译生成文件保留在本地，不上传到 GitHub。
